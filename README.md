# E-Commerce Website - FashionHub

FashionHub is an e-commerce website designed to provide users with a simple online shopping experience. Users can browse products, create accounts, log in, add products to their cart, and place orders. The website also includes an admin section for managing products and orders.

## Features

### User Features
- User registration and login
- Browse available products
- View product details
- Add products to shopping cart
- Manage shopping cart
- Place orders
- View order information
- Session-based user management

### Admin Features
- Admin login
- Add and manage products
- Manage product information
- View and manage customer orders
- Manage user-related information

## Technologies Used

- HTML
- CSS
- JavaScript
- Bootstrap
- PHP
- MySQL

## How to Run

1. Install and open XAMPP.
2. Start **Apache** and **MySQL** from the XAMPP Control Panel.
3. Place the project folder inside the `htdocs` folder.
4. Open **phpMyAdmin** and create the required database and tables.
5. Make sure the database connection settings in the PHP files are correct.
6. Open your browser and go to:

   `http://localhost/FashionHub/`

7. The website will run locally on your computer.

## Database

The project uses MySQL to store user information, product details, shopping cart data, and order information.

## Project Purpose

This project was developed as a web development project to create a simple e-commerce platform with customer shopping and admin management functionality.
